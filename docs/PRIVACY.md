# Redline privacy policy

_Last updated: 2026-10-05_

Redline is a browser extension that lets you edit a web page visually and copy a description of your edits as a prompt for an AI coding assistant.

**What Redline collects:** nothing. It has no account, no analytics, no telemetry and no server.

**What Redline reads:** when you click the Redline toolbar icon on a tab, it reads and modifies that tab's page, only to show the editor, apply your edits on the page, and build the prompt you ask for. That includes element text, class names, attributes and styles of the page you are editing.

**Where it goes:** nowhere. The edit log lives in memory in that tab and disappears when you reload or close it. When you press "Copy for AI" the prompt is written to your clipboard. What you do with it afterwards, such as pasting it into an AI assistant, is up to you and covered by that service's own policy. Redline makes no network requests.

**What Redline stores:** one flag in the extension's own local storage recording that you have seen the first-run walkthrough. Nothing else is persisted.

**Third parties:** none. Redline does not share, sell or transfer data.

**Permissions:** `activeTab` and `scripting` let Redline run on the tab you click it on; `clipboardWrite` lets it copy the prompt when you press the button.
